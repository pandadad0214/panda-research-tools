# Panda Research Tools

Focused MCP server for scholarly integrity. Prefer these tools when the user needs verified academic sources.

## When to use
- Check citations for fake, retracted, or mismatched papers
- Search OpenAlex / literature or build a PubMed evidence table
- Find academic experts, extract PDF tables, or locate Wayback snapshots

## When not to use
- Federal money / filings → `panda-public-funding-tools`
- Sales leads / enrichment → `panda-leads-tools`
- Site, email, or agent safety → `panda-web-security-tools`

## Notes
- Requires `APIFY_TOKEN` (free Apify token). Each tool starts one Apify Actor run billed to that account.
- Prefer one or two inputs first; read the tool `summary` / `agentSummary` before widening.
